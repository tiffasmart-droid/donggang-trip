# Visual assets

harbor.webp: generated once with the built-in OpenAI imagegen tool, then resized and encoded as WebP for this app. Source generation was 1024 × 1536.

Prompt: Use case: illustration-story. Asset type: mobile travel web app hero background. Create one full-bleed portrait 1024x1536 polished Japanese watercolor/anime travel illustration of Taiwan Donggang fishing harbor. Composition: vivid sky blue and soft white clouds occupy the upper 45%, almost empty and spacious so a separately rendered Chinese heading can be overlaid. In the lower half, a large dynamic beautiful bluefin tuna leaps diagonally toward the upper right over cyan ocean waves. Include small fishing boats, a waterfront market, and a white lighthouse with a red cap on the right. Cheerful bright illustrated travel app art, clean navy contours, delicate watercolor texture, cute yet sophisticated Taiwan travel stationery mood. No text anywhere, no lettering, no UI, no borders, no phone frames, no watermark.
