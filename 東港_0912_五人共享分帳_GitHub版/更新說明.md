1. 解壓縮 ZIP，會看到 `東港_0912_五人共享分帳_GitHub版` 資料夾。
2. 開啟 https://github.com/tiffasmart-droid/donggang-trip ，停留在最外層 Code 頁面。

4. 等 Actions 的 Pages 部署顯示成功，再開啟下方網址。

## 這次完成的內容

- 依提供的參考圖重做港口鮪魚插畫、大字東港、圓形旅伴頭像、首頁四格捷徑、底部導覽與中央新增按鈕。
- 不特別顯示旅遊日期。帳目本身的建立時間仍保留。
- 保留姓名：粉粉、夢肉、妗庭、費玉、筠紋；編號與既有帳目對應不變。
- 首頁「我的支出」為代墊金額；「我的應付」為實際分攤金額。最後需轉帳多少，請看結算頁。
- 記帳頁使用分類按鈕、付款人頭像、分攤對象勾選。備註可留空，留空時以分類作為帳目名稱；資料仍使用既有 title 欄位。
- 結算頁提供最少筆數轉帳建議、每人實際花費長條圖及應收／應付明細。
- Supabase URL、Publishable key、0912 房間、RLS 與 Realtime 沿用既有設定。不更動資料表，不新增示意帳目。
- 新版檔案優先連網更新，離線才使用外殼快取；Supabase 帳目不快取。往後修改 config.js 後重新整理即可讀取最新姓名。
